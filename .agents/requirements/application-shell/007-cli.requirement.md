# CLI commands and artifacts

## Requirement

Preconditions:

- The `cslw` executable is invoked with application source or a checked artifact.

Expected behavior:

- `parse` MUST output syntax without starting components.
- `check` MUST validate semantic composition without invoking factories.
- `compile` MUST write versioned checked artifacts with dependency provenance.
- `run` MUST reject an incompatible artifact version or stale dependency rather
  than silently execute outdated composition.
- Invalid commands, source, settings, or runtime failures MUST produce a
  diagnostic and nonzero exit.
- `fmt` MUST NOT be reported as implemented in this initial release.

Postconditions:

- An artifact is build output, never an alternative editable source of truth.
- Tests: application-shell CLI/artifact tests under `test/`.
