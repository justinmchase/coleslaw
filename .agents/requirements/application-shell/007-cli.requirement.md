# CLI commands and artifacts

## Requirement

Preconditions:

- The `cslw` executable is invoked with application source or a checked artifact.

Expected behavior:

- `parse` MUST output a syntax tree without starting components.
- `check` MUST validate semantic composition without starting host drivers or
  running turns.
- `compile` MUST fail with `lowering this program to a Kith scene is the next
  step` until the program is lowered, and MUST NOT write an artifact.
- `run` MUST fail with that diagnostic for a checked program. An artifact
  whose version does not match MUST be rejected as incompatible. A dependency
  marked not present MUST be rejected as stale. `run` MUST NOT execute either
  artifact.
- Invalid commands, source, settings, or runtime failures MUST produce a
  diagnostic and nonzero exit.
- `fmt` MUST NOT be reported as implemented in this initial release.

Postconditions:

- An artifact is build output, never an alternative editable source of truth.
- Tests: `tests/compiler.rs`.
